## 🔭 1. MANIFIESTO ARQUITECTÓNICO (IA SOBERANA & SEINEN NOIR)

Este repositorio unifica la ingeniería del **Bootcamp de Inteligencia Artificial F5**, la infraestructura blindada de **Kilømoodle** y la identidad estética de **Espacio 89**. Todo el código y la documentación responden a cuatro principios rectores:

* **Soberanía Computacional (Local-First):** Entrenamiento ligero, ajuste fino e inferencia de Grandes Modelos de Lenguaje (LLMs) ejecutados directamente sobre Linux local (Arch / EndeavourOS) y APU AMD mediante cuantización optimizada (`GGUF`), sin dependencia obligatoria de APIs privativas.
* **Criptografía Zero-Knowledge (EduCrypt):** Ninguna entrega académica ni peso de modelo se almacena desprotegido. Todo activo pasa por cifrado simétrico autenticado **AES-256-GCM** con envoltura de clave **RSA-2048** en tiempos inferiores a `300 ms`.
* **Erradicación de Sistemas Legacy:** Sustitución total de arquitecturas vulnerables basadas en PHP por servicios compilados en **Go (Golang)** junto con aislamiento por fila **Row-Level Security (RLS)** forzoso en PostgreSQL 17.
* **Estética Seinen & Peritaje de Bajo Nivel:** Precisión quirúrgica en cada script, acompañada por el espíritu vigilante de **Kalicat** y el Concilio ACE.

## 🧠 6. ROADMAP TÉCNICO DEL CURSO DE IA (MÓDULOS 01 AL 04)

### Módulo 01: Ingeniería de Datos y Álgebra Lineal
* Operaciones matriciales vectorizadas con **NumPy**, descomposición en valores singulares (SVD) y análisis de componentes principales (PCA).
* Limpieza reproducible en **Pandas**, detección de anomalías estadísticas (IQR, Isolation Forest) y prevención estricta de *Data Leakage* antes de particionar conjuntos de entrenamiento y prueba.

### Módulo 02: Machine Learning Clásico y Optimización Bayesiana
* Entrenamiento y evaluación de clasificadores y regresores (**Random Forest, XGBoost, LightGBM, CatBoost, SVM**).
* Ajuste automatizado de hiperparámetros mediante **Optuna** con validación cruzada estratificada (`StratifiedKFold`) y análisis de explicabilidad mediante valores **SHAP**.

### Módulo 03: Deep Learning con PyTorch y Procesamiento de Señales
* Construcción de arquitecturas neuronales modulares (`nn.Module`), regularización con *Dropout*, *Weight Decay*, *Batch Normalization* y programación de tasa de aprendizaje (`CosineAnnealingLR`).
* Implementación desde cero del mecanismo de atención escalada por producto punto (**Scaled Dot-Product Attention**):

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

### Módulo 04: LLMs Locales, RAG Zero-Knowledge y Sistemas Multi-Agente
* Creación de modelos personalizados en **Ollama** mediante archivos `Modelfile` ajustados a la memoria disponible en Arch Linux.
* Construcción de pipelines **RAG (Retrieval-Augmented Generation)** 100% locales: ingesta de documentos Markdown/PDF, generación de embeddings en local y consulta vectorial sin exponer datos a terceros.

## 🛡️ 7. KILØMOODLE: BACKEND EN GO, CIFRADO EDUCRYPT Y POSTGRESQL RLS

La plataforma educativa **Kilømoodle** elimina las vulnerabilidades históricas de los gestores de aprendizaje tradicionales mediante una arquitectura en **Go** y **PostgreSQL**:

### 7.1. Pipeline Criptográfico EduCrypt (`< 300 ms`)
1. **Cifrado de Contenido:** Cada archivo o entrega se cifra en tránsito interno usando **AES-256-GCM** con un vector de inicialización (nonce) único y efímero.
2. **Envoltura de Clave:** La clave simétrica generada se cifra con la llave pública **RSA-2048** correspondiente al rol autorizado.
3. **Verificación de Integridad:** El tag de autenticación GCM impide cualquier manipulación de bytes en disco.

### 7.2. Jerarquía de Roles RBAC y Aislamiento PostgreSQL RLS

* **Sys Admin (`K4L1`):** Gobernanza total de infraestructura, auditoría CIS de PostgreSQL, gestión de proveedores IA y llaves maestras EduCrypt. Dispone de conmutación segura a vista de Alumna mediante tokens JWT acotados para pruebas reales.
* **Administradora / Tutora F5:** Permisos de supervisión académica, validación de laboratorios y auditoría con tokens JWT firmados de 72 horas.
* **Colaborador / Mentor ACE:** Creación de materiales didácticos y supervisión de entornos de prácticas.
* **Alumno / Investigador IA:** Aislamiento estricto garantizado por el motor de base de datos mediante `FORCE ROW LEVEL SECURITY` y credenciales protegidas con **Argon2id**.

```sql
-- Migración SQL de Aislamiento Forzoso en Kilømoodle (PostgreSQL 17)
ALTER TABLE kilomoodle_submissions ENABLE ROW LEVEL SECURITY;
ALTER TABLE kilomoodle_submissions FORCE ROW LEVEL SECURITY;

CREATE POLICY student_isolation_policy ON kilomoodle_submissions
    AS RESTRICTIVE
    USING (
        student_id = current_setting('app.current_user_id', true)::uuid
        OR current_setting('app.current_user_role', true) IN ('sys_admin', 'tutora_f5')
    );
```

```python
import torch
import httpx

def auditar_entorno() -> None:
    print(f"[⚡] PyTorch Version : {torch.__version__}")
    print(f"[⚡] Dispositivo Activo: {'GPU/ROCm' if torch.cuda.is_available() else 'CPU Zen 2 Optimizada'}")
    x = torch.randn(3, 3)
    print(f"[🐾] Tensor de Prueba (Kalicat Check):\n{x @ x.T}\n")

def inferencia_soberana(prompt: str, model: str = "anuu-3b") -> str:
    url = "http://127.0.0.1:11434/api/generate"
    payload = {"model": model, "prompt": prompt, "stream": False}
    with httpx.Client(timeout=45.0) as client:
        r = client.post(url, json=payload)
        r.raise_for_status()
        return r.json().get("response", "")

if __name__ == "__main__":
    auditar_entorno()
```
